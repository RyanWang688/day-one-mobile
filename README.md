# Day One · Mobile web app

面向新来澳洲留学生的墨尔本短途探索与生活情景练习。

## 手机测试

部署到 GitHub Pages 后，直接打开站点根链接。入口为 index.html，无原型外框、虚构状态栏或设备缩放。可通过浏览器的“添加到主屏幕”使用独立窗口，支持真实设备 safe area。

## v13 更新

- Journey Tree 每次进入默认显示 Healthcare；各旅程进度仍会保留。标签改为可横向滑动，Campus 与其他标签同为蓝色。
- 新增「住宿租房」（住宿方式选择、安全看房清单、租约类型、押金与房屋状况报告、维修/室友/搬离）和「日常起居」（买菜、天气与防晒、垃圾分类与 10 分退款、开销与求助电话）两条旅程，共 4 个新情景指南。依据 Consumer Affairs Victoria、SunSmart、healthdirect、Victoria Police 等官方页面，2026 年 10 月 20 日核对。
- 所有旅程弹窗左侧的步骤序号与 Healthcare 统一为圆形：当前步骤蓝色，已浏览为绿色勾。
- 底部导航 Saved 改为 Account。账户页包括资料头像、三项统计、各旅程进度、本设备收藏、语言与动效偏好、求助电话，以及清除数据（需二次确认）。数据只保存在本设备。
- Transport、Driving 及新旅程更换为 21 张 Wikimedia Commons 授权照片（CC0 / CC BY / CC BY-SA），旅程之间不重复使用同一张照片，署名见 PHOTO-CREDITS.html。

## v12 更新

- Journey Tree 开放 Campus（校园）旅程，面向第一次来澳洲的国际学生，共 6 步：你的起点 → 落地第一周 → 校园入门设置 → 适应澳洲学习方式 → 课堂之外的生活 → 安顿行动清单。
- Campus 采用 Medicare / Services Australia 的界面模式：左侧色条的页面提示、带编号的任务步骤、关键信息框、方向链接和单选卡片；保持全站统一的蓝色主操作按钮。
- 新增 6 个校园情景指南（截止日前生病、学术诚信、第一份兼职、签租约、签证诈骗来电、想家与情绪低落），以及“两周打工时长”规划器。事实依据为墨尔本大学、Home Affairs、ATO、Fair Work、Consumer Affairs Victoria 等官方页面，2026 年 10 月 20 日核对。
- 新增 smart-motion：内容仅在滚入视口时出现、选项卡滑块跟随、图片解码后淡入、头部滚动阴影、清单勾选动效；连续快速点击或低性能设备会自动缩短动画，并完整遵循“减少动态效果”设置。
- UX 复查修正：导航页到站约 1.2 秒后卡片向左轻晃，提示可左滑进入下一站（闲置 7 秒再提示一次，触碰卡片即取消；减少动态效果时改为提示文字闪烁）；底部导航可访问名称与可见文字一致；首页“More tools”不再是无响应的卡片；Saved 页可打开 Campus 清单；旅程选项卡支持方向键；关闭弹窗不会因动画未完成而卡住。

## v11 更新

- 12 条路线分支，按 Walk / Bike / Transport、6 个主题、可用时间和 3 种当天场景实际筛选。
- 骑行计入解锁与停车；公共交通计入步行接驳、模拟候车和电车路段。没有可用电车路段的候选不会出现在 Transport 结果里。
- 课间短休限定单站且不超过 30 分钟；雨天只推荐室内停留点，两点之间仍需户外出行。
- 合入提供 ZIP 的 GP 诊所、租房看房、餐厅用餐情景模拟，包含三阶段对话、语音朗读、回顾和提示卡收藏。
- 场景采用现有的紧凑 UI；去掉顶部分隔线。保留地图编辑、图文地点面板、AR、问答、中英翻译与单屏总结。

## 演示范围

路线、骑行与公共交通时间是规划模拟，不提供实时导航、班次或骑行通行确认。路线的图形基于已提供的街道与示意路径。出发前确认实际服务、天气、开放时间与通行情况。

AR 使用示例照片；Ask This Place 和情景模拟使用预设对话，没有接入真实识别、实时 AI 或麦克风录音。模拟中的人物、收费和情境是示例。地点面板中的学生评论是明确标注的虚构内容。

## 部署

无需构建或服务器。将此文件夹内容放在仓库根目录，在 Settings → Pages 中选择 main 分支与根目录发布。保留 .nojekyll 和文件夹结构。所有站内资源使用相对路径，支持项目子路径部署。

所有图片保留原权利，来源见 PHOTO-CREDITS.html。地图来源见 MAP-SOURCES.md。本项目是用户研究与界面测试用途的演示应用，不对第三方图片声称开放许可。
